## Program Descriptions
**Task 1 - Functions, Arrow Functions & Control Flow**
`calculateResult(marks)` is a regular function that returns "Pass" for marks of 50 or above and "Fail" otherwise. `displayResult(name, result)` is an arrow function that prints the learner's name and result. Learner data is stored in an array of objects and processed with a `for...of` loop.

**Task 2 - Arrays & Array Methods**
Works on an array of student objects. `forEach()` prints every student's details, `map()` creates a new array of names, and `filter()` creates a new array of students who scored 80 or above.

**Task 3 - Asynchronous JavaScript (Theory)**
The theory answer (Callbacks, Promises, Promise states, Async/Await and the advantage of Async/Await) is in the assignment document.

## Execution Steps
1. Install Node.js (https://nodejs.org) and check with `node -v`.
2. Open a terminal in the project folder.
3. Run each program:
   ```
   node src/task1_functions.js
   node src/task2_array_methods.js
   
   ```
